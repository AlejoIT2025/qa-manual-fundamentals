# QA Manual – Portfolio de Pruebas

Este repositorio contiene ejemplos reales de trabajo como QA Manual, incluyendo:

- Plan de Pruebas (Test Plan)
- Casos de Prueba (Test Cases)
- Reportes de Defectos (Bug Reports)
- Checklist de pruebas
- Evidencias (capturas opcionales)
- Documentación estructurada para entrevistas

Este portafolio demuestra habilidades esenciales requeridas para roles de QA Manual en Europa, EE.UU. y remoto internacional.
