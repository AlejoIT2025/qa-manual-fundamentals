# Checklist de Pruebas de Regresión – Ecommerce Web

Este checklist permite validar rápidamente las funcionalidades críticas del sistema después de un despliegue o corrección de defectos.

---

## 🛒 1. Login / Autenticación
- [ ] El formulario carga correctamente  
- [ ] El usuario puede iniciar sesión con credenciales válidas  
- [ ] Mensaje correcto al ingresar credenciales inválidas  
- [ ] Función "Recuperar contraseña" muestra el formulario  
- [ ] Botones y links funcionan correctamente  

---

## 🔍 2. Búsqueda y Catálogo
- [ ] El buscador muestra resultados relevantes  
- [ ] El filtrado funciona por categoría  
- [ ] El filtrado funciona por precio  
- [ ] Las imágenes del catálogo cargan correctamente  
- [ ] La paginación funciona  

---

## 🛒 3. Carrito de Compras
- [ ] Se puede añadir un producto al carrito  
- [ ] Se puede eliminar un producto  
- [ ] Se actualiza cantidad correctamente  
- [ ] Se recalcula el total  
- [ ] El carrito persiste en la sesión  

---

## 💳 4. Checkout
- [ ] El formulario de datos del cliente carga  
- [ ] Validación de campos obligatorios  
- [ ] Se calcula el costo total con impuestos  
- [ ] Botón de confirmar pedido funciona  
- [ ] Confirmación final muestra número de orden  

---

## 👤 5. Perfil de Usuario
- [ ] La página “Mi Cuenta” carga  
- [ ] Lista de órdenes es visible  
- [ ] Se pueden actualizar datos del usuario  
- [ ] El usuario puede cerrar sesión  

---

## ⚙ 6. Funcionalidad General
- [ ] No hay errores visibles en consola  
- [ ] Todas las páginas cargan en menos de 3 segundos  
- [ ] Todos los links importantes funcionan  
- [ ] El diseño se mantiene estable en escritorio y móvil  

---
