# Bug Report – LOGIN-001

**Título:** El sistema permite login con contraseña incorrecta  
**Severidad:** Alta  
**Prioridad:** Crítica  
**Ambiente:** Chrome 120 / Windows 10  
**URL:** https://fakeecommerce.com/login

## Pasos para reproducir
1. Abrir página de login  
2. Ingresar correo válido  
3. Ingresar una contraseña incorrecta  
4. Clic en "Iniciar Sesión"

## Resultado Esperado
El sistema debe mostrar mensaje: “Credenciales incorrectas”.

## Resultado Actual
El usuario ingresa al sistema sin validación.
