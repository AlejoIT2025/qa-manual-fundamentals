# Test Plan – Sistema Ecommerce Web

## 1. Objetivo
Validar las funcionalidades principales de un e-commerce web: login, catálogo, carrito, checkout y perfil de usuario.

## 2. Alcance
### Incluye:
- Registro y login
- Recuperar contraseña
- Filtrado y búsqueda
- Añadir productos al carrito
- Checkout (pago simulado)
- Perfil y órdenes

### No Incluye:
- Integraciones bancarias reales
- Backend administrativo

## 3. Tipos de Prueba
- Funcional
- UI/UX básica
- Compatibilidad de navegador
- Regresión
- Smoke Test

## 4. Criterios de Entrada
- Ambiente accesible
- Datos de prueba disponibles

## 5. Criterios de Salida
- Cero defectos bloqueadores
- 95% casos ejecutados

## 6. Riesgos
- Cambios sorpresa en producción
- Datos inconsistentes

## 7. Herramientas
- Jira / Trello
- Google Sheets o Excel
